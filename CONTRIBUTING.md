# Contributing / 参与贡献

Accepted contribution areas are feedback, translations, public documentation, and external integration proposals. Product source code remains private.

## Feedback

Search for an existing issue, then use the relevant template. Include the app/build, operating system, interface language, expected behavior, and minimal steps using fictional notes. Acknowledge or discuss an existing report rather than opening a duplicate.

For security concerns or material containing private information, email hello@go2come.com instead of creating a public issue. Do not attach databases, logs containing notes, credentials, or pairing materials.

## Translation and documentation changes

Keep each PR focused on one language or one documentation correction. Explain what changed and where the wording appears. Preserve translation keys, format placeholders, links, and section identifiers. Follow [TRANSLATING.md](TRANSLATING.md).

Product changes proposed in an issue are reviewed by the maintainer and implemented in the private product repository. A proposal does not guarantee implementation, a timeline, or access to private repositories.

## Integration proposals

Describe the tool, intended workflow, data read and written, requested permissions, platforms, and maintenance contact. Check [PLUGINS.md](PLUGINS.md). Do not include working credentials or claim compatibility before a released interface and end-to-end verification exist.

## Review

The maintainer reviews translation meaning and privacy implications, checks public documentation against shipped behavior, and accepts or requests changes. Contributions are credited using the contributor's GitHub identity or requested public name. Do not publish another person's private identity.

Copyright is retained by its respective holders. No general open-source license has been applied; see [RIGHTS.md](RIGHTS.md). Submit material you authored or are authorized to contribute. State any special reuse conditions so the maintainer can confirm them before incorporating your contribution.
